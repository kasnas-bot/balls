# Task 004 — CI: format, analyze, test, import guard

## Goal
Add a GitHub Actions workflow that runs format, analyze and tests for all three packages on every push and pull request.

## Context
CLAUDE.md section 7 (use exactly those commands), docs/DECISIONS.md.

## Scope
- Check `git remote -v`. If the remote is not GitHub, stop and ask.
- Add .github/workflows/ci.yml with:
  - Flutter pinned to 3.38.5 (not floating stable), with pub cache enabled.
  - One `flutter pub get` at the root (the workspace resolves all members).
  - Root: format check on lib and test, flutter analyze, flutter test.
  - shared_physics and server: dart format check, dart analyze --fatal-infos, dart test.
  - An import-guard step that fails if shared_physics/pubspec.yaml or any file under shared_physics/lib mentions flutter, dart:ui, flame or forge2d.
- Your choice of one job or several; explain the choice.

Out of scope: building APKs, signing, deploy steps, code changes (apart from format fixes the checks demand; list them).

## Constraints
Use current major versions of maintained actions. Check the latest release of each before pinning, and record the versions.

## Done when
- The workflow is valid YAML and every command in it passes locally.
- Guard probe: temporarily add `import 'package:flutter/material.dart';` to a shared_physics file, confirm the guard fails, then revert and confirm it passes.
- No push. A real CI run goes in Manual checks.

## Report back
Files changed; local results; action versions; guard probe result; Manual checks.

## Commit policy
Do not commit or push.
